# Переводы контента car-city.pro

Каждый файл здесь — перевод файла из `content/{pages,models,articles}/` с тем же именем.
Путь: `content/i18n/<lang>/<pages|models|articles>/<то же имя>.md`, где lang — `en`, `ky`, `kk`, `uz`.
Адрес страницы на сайте: `/<lang>` + адрес русской страницы (поле `url` не меняется).

## Правила перевода

Сайт собирает страницы из этих файлов автоматически, поэтому структура должна совпадать с русским файлом строка в строку.

1. **Front matter** (между `---`): все ключи остаются. `url`, `mode`, `class`, `date`, `slug` не меняются. Значения `title`, `h1`, `description` переводятся, кавычки остаются валидными (`"…"`, внутренние `"` экранируются `\"`).
2. **Структура Markdown 1:1**: те же заголовки тех же уровней в том же порядке, те же списки, таблицы (текст ячеек переводится), абзацы. Ничего не объединять, не делить, не пропускать и не добавлять.
3. **Не менять никогда**: URL, адреса картинок в `![alt](url)` (alt переводится), числа, цены, телефоны, e-mail, названия марок и моделей машин, госномера, знак `₽`, HTML-комментарии `<!-- -->`.
4. **Служебные слова, которые остаются как есть**:
   - ключевое слово `BREADCRUMBS:` (пункты после него переводятся, разделитель ` > ` остаётся);
   - строка, начинающаяся с `[КАЛЬКУЛЯТОР`, копируется целиком без изменений;
   - в кнопках `[Кнопка: Текст]` слово `Кнопка:` остаётся, переводится только текст;
   - строка, начинающаяся с `Дарим 1-ый день бесплатно`, и **всё после неё до конца файла** копируются без перевода (сайт этот хвост не показывает);
   - заголовок `## IMAGES` и **всё после него** копируются без перевода;
   - заголовок второго уровня, начинающийся с `Нам доверяют`, остаётся по-русски.
   - Хвосты удобно дописывать без перепечатки: перевести начало файла, а хвост добавить командой вроде `awk '/^Дарим 1-ый день бесплатно|^## IMAGES/{f=1} f' ru.md >> out.md`.
5. **Раздел вопросов**: если русский заголовок `##` содержит слово «вопрос», перевод этого заголовка должен содержать: en `questions`, ky `суроо`, kk `сұрақ`, uz `savol`.
6. **Цены** вида `от 1900 ₽/сутки`: число и `₽` как в оригинале, вся строка короткая, на одной строке (`from 1900 ₽/day`, `1900 ₽/kundan`…).
7. **Строки «Ключ: значение»** (характеристики в каталогах) остаются в виде `Ключ: значение`, ключ с заглавной буквы и короче 40 символов.
8. **Отзывы** (`pages/reviews.md`): сами отзывы (имя жирным, строка «дата на [Площадка](url)», текст отзыва) остаются по-русски дословно — это слова реальных людей. Переводятся только заголовки и вводный текст страницы.
9. **Адреса и метро**: для ky и kk остаются по-русски, для en и uz — латиницей транслитом (ул. Удальцова → Udaltsova st.).

## Язык и тон

Простой, живой язык для водителей такси, без канцелярита. Читатели часто из Кыргызстана, Казахстана, Узбекистана.
ky — кыргызский (кириллица), kk — казахский (кириллица), uz — узбекский (латиница, буквы `oʻ gʻ` через U+02BB), en — английский.
